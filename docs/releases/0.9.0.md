# Ghostlink 0.9.0

Ghostlink now includes its own Windows fullscreen helper. A separate Magpie
installation is no longer needed. This is a feature release; the previously
documented security findings remain unresolved.

## Changes

- Pick a window, then use **Fullscreen** or **Alt+Shift+A** to enter and exit.
  **Ctrl+Alt+F11** remains an emergency exit while capture is running.
- A translucent two-line exit reminder appears in the upper-right. It pulses
  for four seconds, then stays subtle. Reduced-motion settings are respected.
- Shared-area tracking keeps source input and fullscreen guest-pointer placement
  aligned. Frame off hides the border while keeping guests visible.
- The main panel is about 20% narrower, with matching Fullscreen and Frame pills.
  The monitor-selection action is named **Entire display**.
- Arrow and ghost pointers retain crisp outlines without blurred drop shadows.
- Fixed overlapping fullscreen toggles, false errors after clean helper exit,
  and fullscreen eligibility after a minimized window is restored.

## Install or update

Download **Ghostlink_0.9.0_x64-setup.exe** below. Tauri 0.8 users can also use the
app's update button. Electron 0.7 and earlier require a manual install.

The updater signature uses the existing signing key. Windows may show an
unknown-publisher warning because this build has no Windows publisher certificate.

## Known limitations

- Fullscreen capture requires **Pick window** and an ordinary windowed source.
  Dragged frames and entire-display selections select pointer-sharing areas;
  they are not fullscreen capture sources. Native exclusive-fullscreen hooks
  are not included.
- This release is Windows x64 only. Linux/X11 is a partial, unverified port;
  its WebRTC runtime and missing native features still need work.
- The existing authentication bypass and connection/message-budget findings
  remain open. Fully exit and reopen Ghostlink before generating a replacement
  secret to revoke an earlier participant. See the
  [security review](https://github.com/paavalipopov/ghostlink/blob/v0.9.0/docs/security-review-0.8.1.md).
- Game-specific behavior and two-PC compatibility still need targeted trials.
  Mixed physical display scaling was not tested.
