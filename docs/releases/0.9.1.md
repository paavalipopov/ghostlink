# Ghostlink 0.9.1

**Update both computers to 0.9.1 before starting a shared session.** This release changes how peers verify the room secret.

## Changes

- Disconnect closes existing and pending connections. After you choose a new secret, both peers must prove they know it before exchanging pointer data. Private trackpad tests use a separate room.
- Ghostlink limits simultaneous connections, incoming message sizes, and pointer traffic so one busy peer has less impact on the app.
- The test trackpad, frame picker, and window-pick marker now open on demand and release their WebViews when finished. In three local Windows trials, median WebView2 memory fell from 131 to 97 MiB at startup and from 147 to 104 MiB after using and closing all three tools.
- The existing updater key now signs on a separate, protected runner. The release workflow verifies the installer signature, version and source information before creating a draft.

## Install or update

Use the in-app update button on Tauri installations, or download **Ghostlink_0.9.1_x64-setup.exe** for Windows x64. Electron installations require a manual update.

**Ghostlink_0.9.1_source.zip** contains the matching GPL-3.0-or-later source, bundled Magpie core, dependencies and build instructions. **SHA256SUMS.txt** lists the asset checksums.
